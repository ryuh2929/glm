# GLM 분석 도구 카탈로그

## 일반화선형모형(GLM)

`glm_regression`

### 1. Description

종속변수의 조건부 평균과 독립변수의 관계를 일반화선형모형(Generalized Linear Model)으로 분석한다. 수치형 독립변수와 절편을 포함한 모형을 적합하여 계수·표준오차·검정통계량·신뢰구간 및 모형 요약을 반환한다.

|family|분석 대상|자동 사용하는 link|설명변수 계수의 의미|
|---|---|---|---|
|`gaussian`|연속형 결과|identity|다른 변수를 고정했을 때 독립변수 1단위 증가에 따른 조건부 평균 차이|
|`binomial`|개별 관측의 0/1 결과|logit|다른 변수를 고정했을 때 독립변수 1단위 증가에 따른 로그 오즈 차이|
|`poisson`|0 이상 정수인 발생 횟수|log|다른 변수를 고정했을 때 독립변수 1단위 증가에 따른 조건부 평균의 로그 차이|

분석의 기본 목적은 변수 간 연관성의 추정이다. 조정한 회귀계수를 인과 효과로 자동 해석하지 않는다. link는 family에 따라 고정되며 사용자가 별도로 지정하지 않는다.

### 2. Input

**필요한 데이터:** 한 행이 하나의 관측 단위인 pandas DataFrame. 종속변수 열 하나와 한 개 이상의 수치형 독립변수 열이 필요하다. CSV를 사용할 때는 호출자가 읽어 DataFrame으로 전달한다.

|Parameter|필수/선택|형식|기본값|의미·조건|
|---|---|---|---|---|
|`data`|필수|pandas DataFrame|없음|분석 데이터. 열 이름은 중복될 수 없음|
|`outcome_column`|필수|문자열|없음|종속변수 열 이름. 빈 문자열 불가|
|`covariates`|필수|문자열 목록(list)|없음|독립변수 열 이름 목록. 최소 한 개, 중복 및 종속변수 포함 불가|
|`family`|선택|문자열|`'gaussian'`|`gaussian`, `binomial`, `poisson` 중 하나. 소문자 이름 사용|

**입력 형식·전처리 조건**

- 지정한 모든 열이 데이터에 존재해야 한다. 분석에 사용하지 않는 열의 결측값은 검사하지 않는다.
- 선택한 열은 숫자로 변환 가능해야 한다. 수치 문자열은 변환하며 범주형 문자열은 자동 인코딩하지 않는다. 이미 0/1로 코딩한 독립변수는 사용 가능하다.
- 선택한 열의 결측값·무한값을 허용하지 않는다. 행을 자동 삭제하거나 값을 대치하지 않으므로 사전에 처리 방법을 결정해야 한다.
- 절편을 자동 추가한다. 별도의 상수열을 넣거나 독립변수 간 정확한 선형 종속이 있으면 오류로 처리한다. 범주형을 사전에 더미화한다면 절편과 중복되지 않도록 한 기준 수준을 제외한다.
- 관측 수는 절편을 포함한 계수 수보다 커야 한다. 이는 최소 실행 조건이며 충분한 표본 크기나 안정적인 추론을 보장하지 않는다.
- 입력 DataFrame의 분석 열을 복사하여 처리하며 원본 데이터를 수정하지 않는다.

|family|종속변수의 추가 조건|
|---|---|
|Gaussian|숫자로 변환 가능한 유한 수치|
|Binomial|0과 1만 사용하고 두 값이 모두 존재. 집계 성공/시도 수 또는 비율 입력은 지원하지 않음|
|Poisson|0 이상의 정수이며 적어도 하나의 양수 관측 필요. 모든 값이 0이면 오류|

**오류 및 예외 처리**

|상황|처리|
|---|---|
|잘못된 입력 자료형·열 이름·변수 목록·family|원인을 설명하는 `ValueError` 발생|
|빈 데이터·결측·무한값·숫자로 변환할 수 없는 값|행을 임의로 제외하지 않고 `ValueError` 발생|
|분포별 종속변수 조건 위반|분포의 입력 조건을 안내하는 `ValueError` 발생|
|상수·선형 종속 설명변수 또는 표본 부족|적합 전에 `ValueError` 발생|
|Binomial 완전분리 경고/예외|정상 결과로 반환하지 않고 `ValueError`로 처리|
|적합 중 처리 대상 예외·미수렴|적합 실패 또는 미수렴 메시지의 `ValueError` 발생|
|계수·추론 결과가 비유한 값이거나 표준오차가 0 이하|유효하지 않은 추론으로 판단하여 `ValueError` 발생|
|AIC·deviance가 비유한 값|`ValueError` 발생|

오류는 문자열이나 오류 dict로 반환하지 않고 예외로 발생한다. 호출 프로그램에서 `try/except ValueError`로 처리할 수 있다. 모든 수치 경고나 불안정 모형을 자동 판별하는 것은 아니다.

### 3. Output

**형태:** 계수 Table과 요약 dict를 담은 Python dict.

```text
{
    "coefficients": pandas.DataFrame,
    "summary": dict
}
```

분석 함수 자체는 파일이나 Figure를 생성하지 않는다. [실행 예제](./run_example.py)가 계수표를 CSV, 요약을 JSON 파일로 저장한다. DataFrame이 포함되어 있으므로 반환 dict 전체가 그대로 JSON 문자열인 것은 아니다.

**계수표 — `coefficients`**

절편 한 행과 독립변수별 한 행을 생성한다. 독립변수가 k개이면 결과는 k+1행이다. 순서는 절편, 입력한 covariates 순서다.

|주요 Column|형식|의미|
|---|---|---|
|`covariate`|문자열|독립변수 이름. `(Intercept)`는 자동 추가한 절편|
|`coef`|수치|링크 척도의 회귀계수|
|`se`|수치|계수의 모형 기반 표준오차|
|`z`|수치|계수/표준오차로 계산한 Wald z 통계량|
|`p`|수치|계수=0이라는 귀무가설의 양측 Wald 검정 p값|
|`ci_lower`|수치|계수 척도의 95% Wald 신뢰구간 하한|
|`ci_upper`|수치|계수 척도의 95% Wald 신뢰구간 상한|

**모형 요약 — `summary`**

|Key|형식|의미|
|---|---|---|
|`family`|문자열|실제 사용한 분포 이름|
|`n_obs`|정수|분석 관측 수. 자동 결측 삭제가 없으므로 정상 실행 시 입력 행 수와 같음|
|`aic`|수치|적합도와 모형 복잡도를 함께 고려하는 AIC|
|`deviance`|수치|적합 모형과 포화모형의 차이를 나타내는 deviance. 분포·분산 처리에 따라 척도가 달라짐|

**실행 결과 예시 — Binomial**

[sample_data.csv](./sample_data.csv)의 disease를 age·smoker로 설명한 결과다. 아래 숫자는 실제 예제 실행 결과를 표시용으로 반올림했다. 합성 데이터의 결과이며 임상적 결론을 의미하지 않는다.

|covariate|coef|se|z|p|ci_lower|ci_upper|
|---|---|---|---|---|---|---|
|(Intercept)|-1.964440|0.442118|-4.443243|0.000009|-2.830976|-1.097903|
|age|0.020397|0.008616|2.367343|0.017916|0.003510|0.037284|
|smoker|0.764598|0.282823|2.703449|0.006862|0.210275|1.318921|

요약은 family=`binomial`, n_obs=300, AIC≈364.576337, deviance≈358.576337이다. 전체 정밀도는 [계수 CSV](./sample_output/binomial_coefficients.csv)와 [요약 JSON](./sample_output/binomial_summary.json)에서 확인할 수 있다.

### 4. Output 검토

**구조의 적절성**

- 계수표와 모형 요약을 분리하여 계수별 해석과 모형 단위 정보를 구별할 수 있다. 수치는 표시용 문자열로 변환하지 않아 후속 계산이나 파일 저장에 사용할 수 있다.
- 계수·표준오차·p값·CI 및 분석 표본 수를 포함하여 기본 회귀 결과 확인에 필요한 정보를 제공한다.
- 수렴하지 않거나 유효한 추론을 만들지 못한 적합은 정상 결과로 반환하지 않는다. 성공한 반환값은 수렴 검사를 통과했다는 뜻이지, 모형 가정이 모두 충족되었다는 뜻은 아니다.

**해석 시 주의사항**

- Binomial의 coef는 로그 오즈, Poisson의 coef는 로그 평균 척도다. **coef·CI를 OR 또는 count ratio로 직접 읽으면 안 된다.** exp 변환한 효과비는 반환하지 않는다.
- 절편은 모든 독립변수가 0일 때의 링크 척도 평균이다. 예제에서 age=0은 관측 범위 밖이므로 절편에 실질적 의미를 부여할 때 주의한다.
- Gaussian도 GLM의 기본 z/Wald 추론을 사용한다. OLS의 소표본 t 검정·t 신뢰구간과 동일하지 않다.
- AIC는 같은 결과 정의와 같은 자료에 적합한 모형 사이에서 비교한다. 예제의 score·disease·visit_count에 대한 AIC를 서로 비교하여 최적 family를 고르는 것은 적절하지 않다.
- p값은 효과의 크기나 중요성을 뜻하지 않는다. 극단적으로 작은 값은 부동소수점 계산 한계로 0으로 나타날 수 있으며, 정확한 확률이 0이라는 뜻은 아니다.

**누락 및 지원 범위**

- 기본 계수 추론에는 필요한 결과가 포함되어 있다. 다만 잔차·영향점·과산포 등의 진단 결과는 없어 이 출력만으로 가정을 확인할 수는 없다.
- 입력 파라미터 전체·라이브러리 버전·경고 목록은 반환값에 별도로 기록하지 않는다. 결과 보관 시 실행 코드와 환경 정보를 함께 보존하는 것이 좋다.
- 가중치, robust/cluster 분산, offset/exposure, 사용자 지정 link, 범주형 자동 처리, 새 데이터 예측, 모델 파일 저장은 지원 범위에 포함하지 않는다. 이러한 기능의 부재를 계산 오류로 분류하지 않는다.

### 5. Assumptions

**공통 가정**

- 관측 간 독립성이 필요하다. 같은 환자의 반복측정이나 기관별 군집 상관을 자동으로 처리하지 않는다.
- 선택한 family와 link가 결과변수의 조건부 평균·변동 구조에 적절해야 한다. 독립변수 자체가 정규분포를 따라야 한다는 뜻은 아니다.
- 연속 독립변수의 효과가 선택한 링크 척도에서 선형이라는 모형을 사용한다. 기본 함수는 비선형 항이나 상호작용을 자동 생성하지 않는다.
- 계수를 구분하여 추정할 수 있어야 하고, 추론에 충분한 관측과 결과의 변동이 필요하다. 정확한 선형 종속 검사를 통과해도 심한 근사 공선성은 남을 수 있다.

|분포|주요 가정·확인 사항|위반 시 주의사항|
|---|---|---|
|Gaussian|조건부 평균의 선형성, 조건부 등분산, 모형 기반 추론을 위한 정규 오차 가정. 잔차 패턴·극단값 확인|이분산·비선형성이 있으면 현재 SE·CI가 부적절할 수 있음. 변수 변환·모형 변경 또는 적합한 분산 추정 검토|
|Binomial|개별 Bernoulli 결과, logit 척도 선형성, 완전·준완전분리 없음, 충분한 사건·비사건 관측|희소 범주·분리에서는 계수와 Wald CI가 불안정함. 현재 경고 검사만으로 모든 준완전분리를 검출하지는 않음|
|Poisson|조건부 평균=분산, log 평균의 선형성, 적절한 count 자료|과산포·과도한 0이면 모형 기반 CI가 지나치게 좁아지거나 모형이 맞지 않을 수 있음. 다른 분포·추론 방법 검토|

Poisson에서 노출시간·관찰 기회가 다른 자료를 단순 count로 비교하면 해석이 달라진다. 이 함수에는 exposure/offset이 없으므로 서로 다른 노출량을 보정한 발생률 분석에 그대로 사용하지 않는다.

결측값을 사전에 삭제·대치했다면 그 방법과 대상자 제외를 별도로 보고해야 한다. 함수 내부에서 결측을 거절한다는 사실이 이미 전처리된 자료의 선택 편향까지 해결하지는 않는다.

### 6. Processing Type

|항목|여부 및 처리 방식|
|---|---|
|모델 학습(Training)|필요. 입력 데이터로 회귀계수를 적합하는 통계모형 추정|
|Batch Processing|불필요. 한 입력 데이터의 분석에 별도 다중 작업 배치 실행이 요구되지 않음|
|단일 실행|가능. 한 번의 함수 호출로 한 family의 계수표·요약 반환|
|내부 반복|statsmodels의 기본 IRLS 적합 사용. 최대 반복 횟수는 100으로 고정하며 미수렴 시 오류|

세 family를 모두 실행하려면 세 번 호출한다. 데이터는 메모리에 올라가며 스트리밍·분산 처리 인터페이스는 제공하지 않는다.
